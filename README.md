# Quantick Tech Website

This is the official website for Quantick Tech, built with a modern, high-performance tech stack.

## 🚀 Deployment

The site is optimized for **Vercel** and **GitHub Pages**.

### How to Activate the Contact Form

The contact form is powered by **Formspree**. To start receiving emails:

1.  Go to [Formspree.io](https://formspree.io/) and create a free account.
2.  Create a new form and copy the **Form ID** (it looks like `mqakevqk`).
3.  Open `index.html` and replace the ID in the form action:
    ```html
    <form action="https://formspree.io/f/YOUR_ID_HERE" method="POST">
    ```
4.  Push the change to GitHub.

Alternatively, if you use the current setup:
1.  Submit the form once on the live site.
2.  Check your email (**quanticktech@zohomail.in**) for a verification request from Formspree.
3.  Click **Verify** and the form will be active!
